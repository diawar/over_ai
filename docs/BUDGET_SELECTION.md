# Распределение бюджета в подборе

Все допустимые полные конфигурации сравниваются сразу. CPU, GPU и плата больше не фиксируются на первом найденном варианте. Сначала выбирается вариант внутри бюджета, затем максимальная полезность по назначению. Если ни один вариант не помещается, возвращается самая дешёвая допустимая сборка с явным превышением бюджета.

Полезность — редакционная эвристика в `config/build-preferences.json` и `tools/pc-builder.cjs`, а не результаты бенчмарков или обещание FPS. Цены не служат показателем производительности. При равной полезности предпочитается меньшая стоимость, затем меньший срок и стабильный порядок SKU. Результат не зависит от порядка каталога.

- CPU: отдельные приоритеты для игр, творчества и офиса, сопоставленные с точным подтверждённым названием модели. Новая модель без профиля получает нулевой приоритет до редакционной оценки.
- GPU: приоритет моделей RTX 50 из подтверждённого пула. Явное пожелание клиента задаёт прежнюю нижнюю границу GPU. Для CS2, Counter-Strike, Valorant и явного киберспорта вес CPU повышается в 1,5 раза, GPU уменьшается до 0,75. Это ограниченное правило, не семантический анализ всех задач.
- Плата: подтверждённые DIMM/M.2, сеть 2.5GbE и выше, Wi-Fi. Дорогой чипсет сам по себе не даёт бонуса. VRM не оценивается по цене или названию.
- RAM: полезный объём до 32 ГБ для игр, 64 ГБ для творчества, 16 ГБ для офиса. Для творчества перебираются 1/2/4 одинаковые товарные позиции с проверкой модулей, слотов, лимита платы и остатков.
- SSD: до 4 ТБ для игр/творчества, до 1 ТБ для офиса. 1/2/4 ТБ дают 2/8/14 условных баллов. Скорость — небольшой вторичный критерий.
- Корпус: небольшой приоритет передним и задним штатным вентиляторам. БП: небольшой приоритет подтверждённой эффективности Gold/Platinum/Titanium, что не является оценкой надёжности или поводом требовать большую мощность.

Бюджет — верхняя граница, а не обязательная сумма к списанию. При отсутствии более полезного доступного варианта остаток сохраняется (`remainingBudget`). 2000/2048 ГБ считаются одним классом, аналогично 1000/1024 и 4000/4096. Паспортная скорость SSD — минимум чтения/записи ступенями 1000 МБ/с, не оценка реальной длительной записи.

Все прежние проверки совместимости, складов, маршрутов и минимальной комплектации остаются. Для нового Ryzen 7 9700X дополнительно требуется подтверждённая поддержка Ryzen 9000 в базе платы и DeepCool AK620 G2 как консервативный выбор премиального воздушного охлаждения. Используется штатный режим 65 Вт; разгон/105 Вт не предполагаются. BIOS конкретной платы проверяется/обновляется при сборке.

Ограничения: один SSD; только подтверждённый каталог; игровые CPU по-прежнему ограничены шестью и более ядрами и используемым лимитом мощности 125 Вт. Для офиса/творчества сохраняется прежнее требование встроенной графики. Нет измеренных сравнений FPS, VRM, акустики, долговечности SSD и полноценной проверки BIOS каждой исторической пары CPU/плата. Это эвристический подбор, не универсальная гарантия оптимальности для любой программы.

Реализация хранит только лучший результат и счётчик допустимых комбинаций. `alternatives` — число комбинаций минус один.
