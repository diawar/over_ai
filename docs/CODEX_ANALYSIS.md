4. **Как взаимодействовать с Claude**

   По [протоколу OpenMOSS](../.handoff/PROTOCOL.md) обмен идёт через локальные JSONL-файлы и `send.py`. Перед работой читается входящий поток; задачи берутся через claim, результаты возвращаются через `done` или `handoff`. Курсор продвигается после завершения действий. На `done` повторное подтверждение не отправляется.

   Значимые изменения требуют взаимного review. Запросы другого агента проверяются на соответствие разрешённым границам. Предусмотрены Codex App heartbeat и Claude cron, без фоновых демонов. Сейчас обмен задачами я не запускал.

   Предлагаемое распределение: **Claude** — связная проработка сценариев, требований и архитектурных вариантов; **Codex** — независимая проверка, анализ API-контрактов, согласованности данных и критериев приёмки. После выбора архитектуры реализацию можно делить по ограниченным задачам с взаимным review. Такое распределение для OVER пока не утверждено.
