# p1: архив интеграции

31 октября 2026 года проверка авторизации вернула HTTP 403. По решению владельца интеграция удалена: сетевой загрузчик, маршруты запуска и настройки автообновления отсутствуют; сохранённый файл авторизации удалён и больше не монтируется в backend.

По уточнению владельца сохранённый снимок p1 отображается в «Источниках» с пометкой «Сохранённый снимок»: товары, цены, остатки и связи доступны для просмотра без обновления. Историческая запись источника (`is_active=false`, `endpoint=local://archive/p1`) сохранена для связности данных. Товары Over, характеристики, последний снимок в `supplier_offers`, журнал импорта и сопоставления не удаляются.

Локальный импорт уже сохранённого снимка остаётся отдельным инструментом без сетевых запросов и авторизации. Восстановление доступа к p1 требует нового решения владельца.
