# CoreLab — интерфейс и диалог ИИ

Локальное приложение без внешних зависимостей. Запустите из корня проекта:

```powershell
node tools/preview-app.cjs
```

Адрес: http://127.0.0.1:8000. Остановка: Ctrl+C. Сервер отдаёт только четыре файла интерфейса из `app/`.

Просмотр всегда мобильный: на компьютере — экран шириной до 430 px в рамке, на телефоне — весь экран. Диалог прокручивается отдельно, шапка и поле ввода остаются на месте. Это предварительный вид веб-интерфейса, не эмуляция встроенных элементов Telegram.

Настройка живого диалога описана в [AI_CONNECTION.md](../docs/AI_CONNECTION.md). Пока ключ и модель не настроены, чат сообщает об отсутствии подключения. ИИ отвечает на описание задач и задаёт уточнения; после бюджета и CPU обсуждает пожелания. Обычный режим рассчитывает системный блок из локального снимка p1 и подтверждённых характеристик. Если полной сборки по этим данным нет, приложение не подставляет детали наугад.

Согласованный демонстрационный сценарий доступен по `http://127.0.0.1:8000/?demo=1`: Старт → имя → потребность → город → назначение и задачи → бюджет вводом → AMD / Intel / на усмотрение специалиста → пример карточки сборки → свободный диалог → явное согласие → оплата → благодарность.

«Апгрейд ПК» и «Подбор товара» видны, но отключены. При выборе другого города основой служит Алматы. Вопросов о мониторе и дополнительных товарах нет. После выбора рассрочки автоматически фиксируется «Рассрочка Kaspi». Полная оплата раскрывает два способа: удалённая оплата Kaspi или картой.

В режиме `?demo=1` нет запросов к ИИ или p1. Пример сборки содержит условные суммы и явно обозначен как не рассчитанный под клиента. Его итог — 450 000 ₸. Для перехода к оплате введите «Сборка устраивает». Произвольные сообщения показываются в чате, но условия не меняют. После перезагрузки диалог начинается заново. В обычном режиме сообщения и условия передаются сервером провайдеру ИИ после настройки подключения; имя остаётся в браузере. Подбор получает данные из локального снимка p1, показывает состав, цену и срок перемещения по позициям, итог, однодневный срок цены и два календарных дня на сборку. Изменения в свободном диалоге пересчитывают предложение; к оплате можно перейти после явного согласия. CRM и Telegram-бот пока не подключены.

Мобильное оформление согласовано владельцем. Telegram SDK и передача заказа менеджеру пока не подключены.
