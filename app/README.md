# CoreLab — интерфейс и диалог ИИ

Интерфейс запускается в составе CoreLab на `http://localhost:5173/mini-app/`.
Для игровой сборки после описания игр клиент выбирает кнопкой разрешение: Full HD, QHD, 4K или «Пока не знаю». Выбор учитывается при подборе; список названий популярных игр обновляется раз в сутки из публичного рейтинга Steam и дополняется постоянными синонимами для игр вне Steam. Рейтинг не является тестом производительности и не задаёт FPS.

Явно выбранные QHD и 4K накладывают минимальные ограничения на GPU и память; 4K также требует минимального уровня CPU. При отсутствии подходящей сборки в бюджете или пределах +5% предложение не формируется, а клиенту показывается минимальная найденная стоимость. Явное изменение разрешения в диалоге запускает новый расчёт.

Для отдельных вручную сверенных сочетаний Cyberpunk 2077, CPU, GPU и разрешения QHD/4K предложение показывает приблизительный FPS калькулятора pc-builds.com со ссылкой. Это дополнительная справка, а не измеренный тест сборки и не балл подбора; для сочетаний без сверенной страницы цифра не показывается.
Для отдельного просмотра интерфейса из корня проекта можно запустить:

```powershell
node tools/preview-app.cjs
```

Адрес: http://127.0.0.1:8000. Остановка: Ctrl+C. Сервер отдаёт только четыре файла интерфейса из `app/`.

Просмотр всегда мобильный: на компьютере — экран шириной до 430 px в рамке, на телефоне — весь экран. Диалог прокручивается отдельно, шапка и поле ввода остаются на месте. Это предварительный вид веб-интерфейса, не эмуляция встроенных элементов Telegram.

Настройка живого диалога описана в [AI_CONNECTION.md](../docs/AI_CONNECTION.md). Ключ и модель задаются в CoreLab. Пока они не настроены, чат сообщает об отсутствии подключения. ИИ отвечает на описание задач и задаёт уточнения; после бюджета и CPU обсуждает пожелания. Обычный режим рассчитывает системный блок из допущенных товаров CoreLab. Если полной сборки по этим данным нет, приложение не подставляет детали наугад.

Согласованный демонстрационный сценарий доступен по `http://127.0.0.1:8000/?demo=1`: Старт → имя → потребность → город → назначение и задачи → бюджет вводом → AMD / Intel / на усмотрение специалиста → пример карточки сборки → свободный диалог → явное согласие → оплата → благодарность.

«Апгрейд ПК» и «Подбор товара» видны, но отключены. При выборе другого города основой служит Алматы. Вопросов о мониторе и дополнительных товарах нет. После выбора рассрочки автоматически фиксируется «Рассрочка Kaspi». Полная оплата раскрывает два способа: удалённая оплата Kaspi или картой.

В режиме `?demo=1` нет запросов к ИИ или каталогу. Пример сборки содержит условные суммы и явно обозначен как не рассчитанный под клиента. Его итог — 450 000 ₸. Для перехода к оплате введите «Сборка устраивает». Произвольные сообщения показываются в чате, но условия не меняют. После перезагрузки диалог начинается заново. В обычном режиме сервер CoreLab вызывает выбранного в настройках провайдера ИИ; имя остаётся в браузере. Подбор получает данные из каталога CoreLab, показывает состав, цену и срок перемещения по позициям, итог, однодневный срок цены и два календарных дня на сборку. Изменения в свободном диалоге пересчитывают предложение; к оплате можно перейти после явного согласия. CRM и Telegram-бот пока не подключены.

Мобильное оформление согласовано владельцем. Telegram SDK и передача заказа менеджеру пока не подключены.

Для бесплатной проверки конфигуратора откройте /mini-app/?no_ai=1: диалог ИИ не вызывается, подбор использует каталог и локальные правила. Обычный адрес /mini-app/ возвращает штатный диалог ИИ. Если ИИ недоступен или на его балансе нет средств, приложение продолжает подбор через локальный конфигуратор.

После предложения клиент может попросить заменить комплектующую: указать точный артикул или название доступного товара, либо сменить тип охлаждения («замените СЖО на воздушный кулер»). Сервер закрепляет запрос при следующих пересчётах и заново проверяет допуск товара, совместимость, цену и остаток. Неоднозначный запрос просит уточнить модель; при отсутствии совместимой сборки предыдущее предложение остаётся без изменений.
