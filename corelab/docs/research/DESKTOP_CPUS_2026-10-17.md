# Исследование свойств: настольные процессоры

Проверено 2026-10-17. Граница: товары категории «Процессоры» типа Desktop/настольные.
Серверные процессоры относятся к отдельной категории и в выборку не входят.
Из каталога сверены точные модели: AMD Ryzen 7 9700X OEM, AMD Ryzen 7 9800X3D OEM,
Intel Core Ultra 7 265K OEM. Исследованы официальные страницы соответствующих
моделей AMD и Intel; суффикс OEM относится к исполнению поставки, свойства ниже —
к самой модели CPU. Охлаждение/комплектация не переносились между исполнениями.

## Предложенная структура каталога

Ниже — внутренние рекомендации по наполнению карточки настольного процессора.

| Свойство | Тип / единица | Статус | Примечание |
|---|---|---|---|
| Сокет | строка | Рекомендуется | Нужен для совместимости. |
| Количество ядер | целое | Рекомендуется | Число физических ядер; для гибридных Intel — сумма P/E. |
| Количество потоков | целое | Рекомендуется | Хранить отдельно от числа ядер. |
| Базовая частота | число, GHz | Рекомендуется | Для гибридных CPU значения P/E различны; одно общее число не выдумывать. |
| Максимальная частота Boost/Turbo | число, GHz | Рекомендуется | Не смешивать с базовой частотой. |
| Кэш L3 | число, MB | Рекомендуется | Хранить отдельно от L1/L2 и суммарного кэша. |
| Тип поддерживаемой памяти | строка | Рекомендуется | Значение может содержать несколько типов; фиксировать пределы производителя. |
| Максимальный объём памяти | число, GB | Рекомендуется | Модельный максимум, не ёмкость установленной памяти. |
| Каналы памяти | целое | Рекомендуется | По спецификации точной модели. |
| Встроенная графика | boolean | Рекомендуется | «Нет» допустимо только при подтверждении точной модели. |

Каждое свойство независимо проверяется по точной модели. Потребляемая мощность
пока не сведена в одно поле: AMD Default TDP и Intel Processor Base/Maximum Turbo
Power — разные определения, их нельзя смешивать. Архитектура (AMD microarchitecture
против Intel codename) также пока оставлена справочной, а не частью общей структуры.

Для отдельной категории серверных процессоров нужно провести собственное исследование
её 2–5 точных моделей и создать отдельный шаблон свойств. Перечисленные свойства
относятся только к внутреннему каталогу и совместимости ПК.
