# Просмотр источников

Маршрут: `/admin/sources`. Добавлена отдельная вкладка «Источники».

Экран получает только локальные данные через защищённые GET API:
`/api/v1/admin/sources` и `/api/v1/admin/sources/{id}/products`.
Поддержаны выбор источника, поиск по названию/артикулу/SKU/производителю,
категория, архивный статус, сортировка, серверная пагинация и карточка товара
с тремя ценами и исходными складскими строками. Нулевые цены отображаются
как неуказанные. Обновление просмотра не запускает импорт.

15 октября 2026 выполнена начальная загрузка p1, затем обновление из свежего
полного снимка. В снимке 30 401 позиция, снимок получен 15 октября 2026.
В БД остаются предложения из истории, поэтому текущие и отсутствующие в
последнем снимке записи учитываются отдельно.

Согласованная модель: CoreLab — агрегатор прайс-листов; каталог CoreLab
независим от предложений поставщиков. p1 — первый источник. Каждая новая
позиция создаётся 1:1 со связью; свойства принадлежат товарам CoreLab.
Повторные импорты не затирают локальные свойства.

Предложения поставщиков хранятся отдельно от товаров CoreLab в
`supplier_offers`; связь задаётся `product_source_links`. Первая загрузка
создаёт товар CoreLab 1:1 для каждого SKU p1, а следующие обновляют только
предложение источника, сохраняя локальные свойства товара. Категории относятся
к каталогу CoreLab. В карточке показывается состояние и название связанного
товара CoreLab. После полного снимка старые предложения помечаются как
отсутствующие, их карточки и свойства CoreLab сохраняются. Список по умолчанию
показывает актуальные предложения; отдельный фильтр открывает старые записи.

Проверено: production build, 6 frontend-тестов (4 новых: карточка, запросы
фильтрации/пагинации, пустая БД, повтор после ошибки), тесты импортёра,
миграции и авторизованный API smoke. Последний импорт: `docs/P1_IMPORT.md`.
