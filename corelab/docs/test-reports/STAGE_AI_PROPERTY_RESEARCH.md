# Формирование структуры свойств с ИИ

Дата: 2026-10-17. Это завершённая часть требований к исследованию свойств категории,
а не завершение этапа 8 по заполнению карточек товаров.

## Результат

- В меню админки под «Журналом» появился раздел «Настройки» для OpenAI API-ключа и ID модели;
  модель по умолчанию — `gpt-5.5`, ID можно изменить в интерфейсе.
- Ключ хранится зашифрованным в `ai_provider_settings`; открытое значение не возвращается,
  не попадает в аудит и не пишется в журналы сервера. Ключ шифрования выводится из
  `SESSION_SECRET`; после смены этого секрета ключ потребуется сохранить повторно.
- На странице свойств пустой категории доступна кнопка «Сформировать свойства с ИИ».
  Сервер запрашивает 2–5 моделей, веб-поиск и строго типизированный JSON-ответ через
  OpenAI Responses API. В каталог записываются только рекомендованные внутренние свойства.
- Сохраняются модели, URL источников, код модели ИИ, дата исследования и аудит операции.
  Проверка структуры учитывает сохранённую запись исследования.
- Перед записью сервер повторно проверяет, что структура осталась пустой; весь набор
  свойств сохраняется одной транзакцией. Заполненные категории не перезаписываются.
- Продуктовые карточки и их значения этим действием не меняются.

## Проверки

- `docker compose up -d --build backend frontend` — успешно; локальные сервисы запущены.
- `docker compose exec -T backend alembic current` — `0008_ai_provider_settings (head)`.
- `docker compose exec -T backend pytest -q --tb=short` — 61 passed.
- `npm.cmd test -- --run` — 19 passed.
- `npm.cmd run build` — production build успешно.
- `npm.cmd run test:e2e` — 3 passed, включая генерацию структуры с замоканным исследованием.
- `git diff --check` — успешно.

Реальный запрос к OpenAI не выполнялся: владелец ещё не сохранил API-ключ. Перед
использованием его можно проверить в разделе «Настройки». Исследование категории —
синхронный запрос с тайм-аутом до 120 секунд; автоматическое заполнение карточек товара,
фоновые задания и загрузчик этапа 8 остаются следующей работой. Проверка домена
сопоставляет основное имя домена с известным производителем из каталога и требует URL
из веб-цитат; это автоматическая проверка источника, а не внешняя сертификация владения
доменом.
