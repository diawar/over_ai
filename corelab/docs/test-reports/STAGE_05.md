# Этап 5 — свойства каталога

Дата обновления: 2026-10-17.

## Итог

Полный набор требований Google Merchant Center отключён. В структуру добавлены только
десять выбранных полей: описание, основная и дополнительная ссылки на изображения,
гарантия, MPN, состояние, размеры и вес. Остальные требования GMC не проверяются.

Для настольных процессоров проверены официальные страницы трёх точных моделей AMD
и Intel и записаны десять свойств со статусом `internal/recommended` в категорию
«Процессоры» ID 44. Категория серверных процессоров ID 284 не изменялась. Карточки
товаров и их значения не изменялись.

Из прежних архивированных правил активируются только совпадающие с выбранным списком.
Остальные исторические записи сохраняются выключенными и не участвуют в проверках.

Миграция `0006_archive_merchant_rules` повторяет архивирование на существующих
установках. Понижение версии миграции намеренно не реактивирует архивированные
правила.
