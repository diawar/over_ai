# Этап 10А — вкладка «Свойства»

Дата: 2026-10-18

## Реализация

- В боковой навигации добавлен раздел «Свойства» (`/admin/properties`). Теперь он показывает справочник свойств и все фактически записанные значения выбранного свойства с числом товаров.
- Для свойств всех типов можно выбрать два или более значения. Кнопка над таблицей открывает окно в стиле массового редактирования «Каталога»: выбор итогового значения, предпросмотр и подтверждение. API проверяет актуальные количества, обновляет записи одной транзакцией, сохраняет источники, пересчитывает допуск и пишет аудит.
- Значения всех типов можно добавлять, изменять и удалять через окна вкладки. Отдельная таблица `property_values` хранит созданные значения даже до назначения товарам. Изменение записанного значения обновляет связанные карточки; подтверждённое удаление убирает запись свойства из связанных карточек. Операции сверяют количество товаров, пересчитывают допуск и пишут аудит с автором.
- Нормализатор новых GPU значений удаляет префиксы `NVIDIA` перед `GeForce` и `AMD` перед `Radeon` при ИИ-загрузке и ручной/массовой записи. Существующие значения автоматически не переписываются.
- Категории каталога CoreLab, путь категории в дереве и число её активных внутренних свойств теперь доступны по `/admin/properties/categories`. Есть поиск и фильтр категорий с настроенными и пустыми структурами.
- Каждая категория ведёт в существующий редактор `/admin/categories/{id}/properties`. Для самостоятельных значений добавлена миграция БД `0010_property_values`.
- Список получает данные через защищённый `GET /api/v1/admin/properties/categories`; категории поставщиков и архивные правила в подсчёт не попадают.
