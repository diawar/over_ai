# Заполнение характеристик через XLS

На странице каталога рядом с «Оценки CPU и GPU» находятся «Скачать XLS по 10 товаров» и «Загрузить и применить».

1. Выберите категорию и при необходимости введите поиск. Выгрузка охватывает все страницы этой выборки, включая вложенные категории.
2. Выберите обязательные характеристики, обязательные для подбора ПК или их объединение. Выгружаются активные технические свойства категорий, а также неполные JSON разъёмов с неизвестными параметрами. Общие поля товарного фида не редактируются этим файлом.
3. Скачайте ZIP-архив и распакуйте его. В каждом XLS все отсутствующие свойства 10 товаров, в последнем может быть меньше. Товар не разбивается между файлами. Файлы последовательно пронумерованы. Одна строка соответствует одному свойству конкретного товара. Каждый файл содержит лист «Инструкция» и независимо загружается для применения. При пустой выборке архив не создаётся.
4. Передайте файл AI или заполните вручную. Меняйте только «Новое значение», «Ссылка на источник», «Примечание». Сохраняйте XLS Excel 97–2003, заголовки, листы и служебные столбцы. Пустое новое значение означает пропуск, `0` и `Нет` — реальные значения.
5. Списки и разъёмы задавайте JSON-массивами. В неполном JSON сохраняйте подтверждённые параметры и добавляйте неизвестные. Числа вводите без единиц, логические значения — «Да»/«Нет». Соблюдайте ограничения и допустимые значения в строке.
6. Загрузите отдельный XLS или весь ZIP через «Загрузить и применить». Распаковывать ZIP не требуется: предварительный просмотр объединяет все XLS, показывает файл и строку при ошибке. Сервер проверяет принадлежность организации, точные ID/SKU/артикул/название, неизменность исходного значения и структуры, формат и нормализацию. Любая ошибка или дублирование заполненной строки между файлами блокирует весь пакет. Предварительный просмотр показывает нормализованные значения.
7. Нажмите «Применить характеристики». Запись выполняется одной транзакцией, проверяет сохранённые значения повторной нормализацией и пересчитывает допуск. Старые значения и источники сохраняются в журнале. Известные характеристики не перезаписываются, подтверждённые части JSON не удаляются.

Файл XLS или ZIP ограничен 20 МБ. В ZIP допускаются только XLS, до 1000 файлов и до 100 МБ в распакованном виде. Общий предел — 100 000 строк на пакет. XLS разбивается на листы по 60 000 строк. Для больших очередей используйте категории или поиск. При ошибке устаревших данных скачайте новый файл. Отправка файла сама по себе не вызывает платный AI или загрузчик характеристик.

Источники: сначала точная спецификация производителя; согласованные резервные источники — shop.kz, dns-shop.kz, technodom.kz и pricerunner.com по HTTPS. PriceRunner сохраняется с типом `retailer_site`, а не как производитель. Другие национальные домены PriceRunner автоматически не разрешены.
